# DailyLife

DailyLife is a full-stack personal productivity application combining:

* Task Management
* Personal Diary
* AI Assistant

## Architecture

```text
React
  ↓
Spring Boot
  ↓
PostgreSQL
  ↓
Spring AI
  ↓
LLM + RAG
```

## Planned Features

### Task Manager

* Create tasks
* View tasks
* Update tasks
* Delete tasks
* Complete tasks

### Diary

* Create diary entries
* Search diary entries
* Filter entries
* Paginate entries

### AI Assistant

* Diary summarization
* Mood analysis
* Task suggestions
* Daily planning
* Questions about diary history using RAG
